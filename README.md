Superstore Sales Analysis Using Python

 Project Overview
This project analyzes retail sales data to identify sales trends and business insights.

Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

 Analysis Performed
- Total sales and unique orders
- Category-wise sales analysis
- Region-wise sales analysis
- Monthly sales trends
- Customer segment analysis
- Top-selling products and sub-categories

 Key Findings
- Technology is the highest-selling category.
- The Consumer segment generates the highest sales.
- Phones and Chairs are among the top-selling sub-categories.
